##  Time Complexity Summary

| Problem Type          | Time Complexity |
| --------------------- | --------------- |
| Bubble Sort           | O(n²)           |
| Selection Sort        | O(n²)           |
| Insertion Sort        | O(n²)           |
| Kth Element (Sorting) | O(n log n)      |
| Merge-based Problems  | O(n log n)      |
| Two Pointer Problems  | O(n)            |
