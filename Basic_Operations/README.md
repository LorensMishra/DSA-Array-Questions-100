This repository contains basic to intermediate **Data Structures & Algorithms (DSA)** problems solved in Python.

The goal is to build strong fundamentals by practicing **array-based problems step by step**.

---

## Topics Covered
- Array Basics
- Searching & Traversal
- Sorting Concepts
- Frequency Counting
- Rotation Problems
- Duplicate Handling

---

## Problem List

### Day 1 – Array Basics

1. Sum of array elements  
2. Maximum element in array  
3. Minimum element in array  
4. Average of array  
5. Reverse array (in-place)  
6. Check if array is sorted  
7. Count even and odd elements  
8. Second largest element  
9. Second smallest element  
10. Frequency of elements  
11. Remove duplicates from array  
12. Rotate array by one  
13. Rotate array by k steps  
14. Sum of even and odd indices  
15. Check if element exists
