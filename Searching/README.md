This repository contains implementations of **important searching and array-based problems** using Python. These problems are commonly asked in **coding interviews**, **DSA rounds**, and platforms like LeetCode, HackerRank, and HackerEarth.

---

##  Files Included

| File Name                                                | Description                                       |
| -------------------------------------------------------- | ------------------------------------------------- |
| `16_implement_linear_search_in_array.py`                 | Basic linear search (works on unsorted arrays)    |
| `17_implement_binary_search_sorted_array.py`             | Binary search (efficient for sorted arrays)       |
| `18_find_first_occurrence_of_an_element.py`              | Finds first occurrence using binary search        |
| `19_find_last_occurrence_of_element.py`                  | Finds last occurrence using binary search         |
| `20_count_total_occurrence_of_the_element.py`            | Counts total occurrences using first & last index |
| `21_find_the_index_of_the_maximum_element.py`            | Finds index of maximum value                      |
| `22_find_the_index_of_minimum_element.py`                | Finds index of minimum value                      |
| `23_find_element_in_rotated_sorted_array.py`             | Search in rotated sorted array                    |
| `24_search_for_a_number_in_2d_matrix_row_wise_sorted.py` | Search in 2D sorted matrix                        |
| `25_find_if_there_exists_a_pair_with_a_given_sum.py`     | Pair sum problem (two-pointer / hashing)          |

##  Time Complexity Summary

| Algorithm              | Time Complexity |
| ---------------------- | --------------- |
| Linear Search          | O(n)            |
| Binary Search          | O(log n)        |
| First/Last Occurrence  | O(log n)        |
| Pair Sum (Two Pointer) | O(n)            |
| Matrix Search          | O(n + m)        |
